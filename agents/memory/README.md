# Durable agent memory

Agent memory stores reusable, verified lessons. It is not a transcript, task log, backlog, or substitute for Notion.

Read `shared.md` plus only the file for the current primary role. Add an entry only after closure review or Epic retrospective confirms it is broadly reusable.

## Entry template

```markdown
## YYYY-MM-DD — Short lesson

- Evidence: file, PR, test, incident, or Notion decision
- Lesson: the reusable fact or working agreement
- Applies when: scope in which the lesson is valid
- Invalidated when: evidence that would make the lesson stale
```

Do not store secrets, personal data, raw external responses, speculative ideas, or volatile status. Keep each entry short enough to save future context rather than consume it.
